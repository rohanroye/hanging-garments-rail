# Hanging Garments Rail

A customizable Shopify section that displays garments on a hanging rail. It includes a swipeable carousel, hover effects, and a product details popup.

## Features

- Steel, matte black, or brass rail finishes
- Horizontally scrolling garment carousel
- Hover animation and optional captions
- Popup with product image, details, and link
- Adjustable colors, spacing, sizing, and effects
- Shopify product integration or custom garment details

## Installation

1. In Shopify admin, go to **Online Store → Themes**.
2. Duplicate your theme so you can safely preview the section.
3. On the duplicate theme, choose **… → Edit code**.
4. Under **Sections**, choose **Add a new section**.
5. Name it `hanging-garments-rail`.
6. Replace the new file’s contents with the code in `hanging-garments-rail.liquid`, then save.
7. Open **Customize** for the duplicate theme.
8. Add the **Hanging Garments Rail** section to the page where you want it.
9. Add a **Garment** block for each item and choose its images or Shopify product.
10. Preview the page on desktop and mobile. When you’re happy with it, publish the theme.

## Adding garments

For each Garment block, you can:

- Add a side image and an optional front image.
- Select a Shopify product to use its title, price, description, image, and link.
- Or enter custom title, price, description, and link details.

Use transparent PNG or WebP images that include the hanger for the best result.

## Customization

Use the section settings in Shopify’s theme editor to adjust the rail finish, garment size, spacing, colors, captions, carousel controls, popup appearance, and other options.

The optional button below the garments can also be customized. For example, change its label to **More designs** and add a link to your website or another page.
